# HistoricalHex — план v2

Форк [daulet123z/hexland](https://github.com/daulet123z/hexland) → [PolyAtomicIon/HistoricalHex](https://github.com/PolyAtomicIon/HistoricalHex).
Цель: та же механика гексов, но каждая партия — историческая эпоха со своим лором (связка с Zaman),
премиальный интерфейс (Liquid Glass), живая карта (2D / 2.5D / 3D), сервер вместо Firebase.

Игра в основном **в одной комнате**: телевизор/ноут + телефоны.

---

## 1. Что берём из hexland как есть

- `src/engine/` — чистый движок правил (TS, без сети и UI, 101 тест). Переезжает **на сервер** без изменений.
- `src/bots/` — боты трёх уровней. Тоже на сервер: бот вместо вышедшего работает, даже если ведущий закрыл вкладку.
- Тесты `test/*.test.ts`.

Всё остальное (`net/`, `host/`, `play/`, `board/`) переписываем.

## 2. Сеть: свой сервер вместо Firebase

| | Было (Firebase) | Стало |
|---|---|---|
| Кто считает правила | вкладка ведущего | Node 22 сервер на `77.246.247.9` |
| Транспорт | Realtime DB | WebSocket (`wss://bekzaty.abmco.kz/catan/ws`) |
| Скрытые карты | правила БД | сервер шлёт каждому только его руку |
| Ведущий уснул | игра встаёт | игра идёт дальше |
| random.org | из браузера, без ключа | с сервера, через API-ключ, кэш бросков |
| Хранение | Firebase | SQLite-снимок партии после каждого хода |

**Почему не Yjs для состояния игры.** Yjs — CRDT: каждый участник получает весь документ и может его менять.
Для настолки со скрытой рукой и колодой карт развития это плохо: чужие карты окажутся на телефоне, а правила
некому проверять. Нужен один авторитетный сервер. Yjs можно взять позже для общих вещей без секретов
(общий лист заметок, «доска» реакций), если понадобится.

Протокол (JSON по WS):
- клиент → `join {pin, name, color, token}`, `action {...}`, `plan {...}` (только себе), `react {emoji}`, `dice:physical {a,b}`
- сервер → `snapshot {public, private, you}`, `event {...}` (для анимаций и звуков), `react`, `error`

Переподключение — по `token` в `localStorage`, как сейчас.

## 3. Деплой

- статика: `dist/` → `/var/www/catan/` (rsync, как Zaman)
- сервер: `/opt/historicalhex/`, `systemd historicalhex.service`, `/usr/local/bin/node22`, порт `127.0.0.1:8790`
- nginx `bekzaty.abmco.kz`: `location /catan/` (alias на статику) + `location /catan/ws` (proxy_pass, Upgrade)
- `scripts/deploy.sh` — сборка, rsync, рестарт сервиса, curl-проверка

## 4. Интерфейс

- React 19 остаётся: [Vercel UI SDK](https://infoq.com/news/2026/11/vercel-ui-sdk) (`@ui-sdk/react`, публичная бета) —
  это headless-поведения (фокус, попапы, drag), сам React не заменяет. Берём его для поведения, стиль наш.
- **Без деления экрана пополам.** Карта на весь экран, поверх — плавающие стеклянные панели (Liquid Glass):
  сверху игроки и очки, снизу док: руки ресурсов + главные действия. Всё остальное — шторки.
- Шторки: свайп за палец, пружина, snap-точки, прерываемые (обмен, карты развития, план хода, лор).
- Микроанимации, вибрация (`navigator.vibrate`), звуковой пакет, никаких прыжков вёрстки
  (фиксированные размеры доков, `tabular-nums`, skeleton вместо пустоты).
- Все поля ввода ≥ 16px.

## 5. Карта: 2D / 2.5D / 3D

Один рендер на three.js (`@react-three/fiber`), три камеры:
- **2D** — сверху, ортографическая; плоские стилизованные тайлы, живое море на шейдере, лёгкое покачивание.
- **2.5D** — изометрия, ортографическая камера под углом, тайлы с объёмом и анимированные мелочи (дым, мельницы, овцы).
- **3D** — перспектива, low-poly, облёты камеры к событиям (разбойник, новый город, самый длинный путь).

Море — общий шейдер (волны, пена у берега, блики). На слабых телефонах — упрощённый режим.

Бесплатные ассеты (CC0, можно в коммерции):
- [KayKit Medieval Hexagon Pack](https://kaylousberg.itch.io/kaykit-medieval-hexagon) — гексы, здания, дороги, low-poly
- [Kenney Hexagon Kit](https://kenney.nl/assets/hexagon-kit), [Quaternius](https://quaternius.com) — модели
- [Kenney Audio](https://kenney.nl/assets?q=audio), freesound (CC0) — звуки
- Недостающее (карты, иконки ресурсов эпохи, портреты) — генерим через Codex.

## 6. Кубики

- Источник: random.org (сервер), сбалансированные, системный.
- **Физические кубики**: бросающий вводит два числа на телефоне (крупные кнопки 1–6), на ТВ — «Бросок вручную: 4 + 3».
- В свой ход — авто-бросок (можно выключить).
- Анимация: грани мелькают и замедляются до выпавших, звук «тын-тын». На 7 — «тудум», тряска, разбойник.

## 7. Сочность событий

Кинематографичные вставки на ТВ + короткие на телефоне: рыцарь (атака), монополия, изобилие, дорожное строительство,
самый длинный путь / самая большая армия, победа. Звук на каждое событие. Эмодзи-реакции друзьям (летят по экрану ТВ).

## 8. Планировщик хода (главная фича)

Пока ходят другие:
- ставишь «призраки» построек на карте, собираешь заготовки обменов;
- после каждого чужого хода план перепроверяется движком: «перекрёсток занял Даулет — план сломан», «хватает ресурсов на город»;
- в свой ход — «Выполнить план» одной кнопкой (шаги по очереди, с остановкой на первом невозможном).

Подсказки:
- чужое предложение обмена, которое тебе нечем закрыть: «У тебя нет камня — это не к тебе. Предложить встречное?»
- «Тебе не хватает 1 пшеницы до города — у Аскара есть»; «Порт 2:1 по дереву выгоднее банка».

## 9. Сеттинги (связь с Zaman)

Пакет эпохи: `id`, название, эпоха/регион, названия 5 ресурсов и местностей, палитра, вступление (лор на 30 сек),
реплики рассказчика на события, образ разбойника, ссылки на статьи Zaman. 50 пакетов генерим ИИ, проверяем вручную.
Первые три: «Великий Шёлковый путь», «Казахское ханство», «Золотая Орда».

## 10. Этапы

1. Сервер на Node + WS, движок и боты на сервере, деплой на `/catan`. Баг с выходом ведущего уходит сам.
2. Новый экран игрока: карта на весь экран, стеклянный док, шторки. Кубики (физические, авто, анимация, звук).
3. Рендер карты three.js: 2D с шейдером моря → 2.5D → 3D с облётами. Ассеты KayKit.
4. События, звуки, реакции.
5. Планировщик хода + подсказки.
6. Сеттинги: формат пакета, 3 эпохи вручную, затем генерация остальных.
