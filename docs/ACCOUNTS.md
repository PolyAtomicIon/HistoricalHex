# Профили, Telegram, PWA

## Что уже работает

- **Профиль на устройстве.** Игрок определяется секретом в localStorage (как и раньше). После первой партии создаётся профиль: рейтинг (Эло), партии, победы, серия дней (по Алматы), коллекция эпох. Таблица лидеров — в профиле и по адресу `/catan/api/leaderboard`.
- **Хранилище.** `node:sqlite` в `/var/lib/historicalhex/hh.sqlite` (Node 22). Без него (Node 20, тесты) — в памяти.
- **Рейтинг.** Попарный Эло: каждый соперник — отдельная «дуэль». Боты — неподвижные ориентиры 800/1000/1200 с весом 0.5. Партия только с ботами двигает рейтинг вдвое слабее. K = 40 первые 10 партий, потом 24.
- **Telegram Mini App.** Если игра открыта внутри Telegram, клиент сам отправляет `initData`, сервер проверяет подпись (HMAC с ключом `WebAppData`) и привязывает устройство к профилю с этим `tg_id`. Первый вход «повышает» гостевой профиль — статистика не теряется. Второе устройство с тем же Telegram видит тот же профиль.
- **PWA.** `public/sw.js`: страница — сначала сеть, ассеты — из кэша, арт эпох — из кэша с фоновым обновлением; `/ws` и `/api` мимо. Кнопка «Установить» на главной (на iOS — подсказка «На экран Домой»). Заставка — в `index.html`, гаснет после первого рендера.

## Что нужно сделать владельцу (один раз)

1. В Telegram открыть @BotFather → `/newbot` → имя и username (например, `historicalhex_bot`). Сохранить токен.
2. `/newapp` → выбрать бота → название, описание, картинка 640×360 → URL `https://bekzaty.abmco.kz/catan/` → short name `play`. Ссылка на игру: `https://t.me/<бот>/play`, приглашение в комнату: `https://t.me/<бот>/play?startapp=<PIN>`.
3. `/setmenubutton` → тот же URL (кнопка «Играть» в чате с ботом).
4. На сервере создать `/etc/historicalhex.env` (владелец root, `chmod 600`):

   ```
   TG_BOT_TOKEN=<токен от BotFather>
   TG_BOT_NAME=<username бота без @>
   ```

5. `systemctl restart historicalhex`. Служба уже читает этот файл (`EnvironmentFile=-/etc/historicalhex.env`).

Токен в репозиторий и клиент не попадает.

## Интеграция с AQL Portal (дальше)

Портал уже знает `telegram_id` учеников (`telegram_accounts`). Простейший путь:

1. Общий ключ — `telegram_id`. Добавить в игру `GET /catan/api/portal/players?tg_ids=…` с `Authorization: Bearer PORTAL_API_KEY` → статистика по ученикам.
2. Кнопка «Играть» в портале → `t.me/<бот>/play`, личность совпадёт сама.
3. Для учеников без Telegram — подписанный билет от портала (`payload.hmac`, 60 с).

Вход через Login Widget в Казахстане ненадёжен (`telegram.org` блокируется), поэтому для браузера дальше нужен вход диплинком `t.me/<бот>?start=login_<nonce>` с long-poll `getUpdates` — сервер уже умеет проверять подписи, осталось добавить опрос бота.
