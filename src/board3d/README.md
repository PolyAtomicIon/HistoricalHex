# board3d — WebGL-карта (React Three Fiber)

`import Board3D from './board3d/Board3D'` — замена SVG-`<Board>`: все пропсы `BoardProps`
(`view, colors, highlight, onVertex/onEdge/onHex, recent, selected, flash, className`) плюс:

| проп | что делает |
|---|---|
| `mode: '2d' \| '25d' \| '3d'` | вид сверху / изометрия / перспектива с вращением. Смена режима — плавный пролёт камеры (~0.7 с), без ремонта канваса |
| `palette?: {sea, seaDeep, accent, light}` | цвета моря, подсветок и солнца |
| `focus?: {hex?, vertex?, edge?, key}` | смена `key` — камера летит к месту и возвращается (2d: мягкий наезд) |
| `ghosts?: {vertex?, edge?, kind, color, broken?}[]` | полупрозрачные пульсирующие «планы» с пунктирным контуром |
| `shake?: number` | смена значения — тряска ~400 мс (отключена при prefers-reduced-motion) |
| `lowPower?: boolean` | dpr=1, без теней и MSAA, меньше сетка воды, анимации пропсов через кадр |

Канвас заполняет родителя (`width/height: 100%`), прозрачный. Жесты: 2d/25d — перетаскивание (панорама) и щипок/колесо (зум) с ограничением;
3d — вращение/наклон одним пальцем, щипок/колесо — зум, цель камеры не уходит с острова.

Файлы: `Board3D.tsx` (канвас, камера, жесты, сцена), `Sea.tsx` (шейдер моря + пена по полю расстояний),
`Terrain.tsx` (плитки и процедурные пропсы, инстансами), `Markers.tsx` (жетоны, гавани, подсветки, вспышки),
`Pieces.tsx` (дороги, дома, города, призраки, разбойник, облачко), `world.ts`, `rig.ts`.
`dev.tsx` + `dev.html` — песочница для ручной проверки (нигде не подключена): `npm run dev` → `/src/board3d/dev.html`.
