# Хексленд: как запустить

Настольная игра про ресурсы, торговлю и стройку на острове из шестиугольников.
Общая карта показывается на большом экране (ноутбук у телевизора), игроки заходят с телефонов по PIN или QR-коду.
В игре от 3 до 6 участников, недостающих можно заменить ботами.

**Сайт уже выложен, ничего ставить не нужно:**

| Кто | Адрес |
|---|---|
| Ведущий (экран у телевизора) | https://hexland-540c6.web.app/host.html |
| Игроки | https://hexland-540c6.web.app (или QR с экрана ведущего) |

Нужен только интернет на всех устройствах. Игроки могут быть и в разных городах.

---

## Как начать партию

### Ведущий
1. Открой `https://hexland-540c6.web.app/host.html` на ноутбуке и выведи экран на телевизор.
2. Выбери настройки и нажми **Создать игру**:
   - **Ждать отвалившегося игрока:** 1, 2, 3 или 5 минут;
   - **Если игрок не вернулся:** «за него играет бот» (по умолчанию) или «решает ведущий»;
   - **Очков для победы:** 8 (быстрая), 10 (обычная) или 12 (длинная).
3. На экране появятся **PIN** и **QR-код**.
4. При нехватке людей нажми **Добавить бота**. Есть три бота:
   - **лёгкий** ходит почти наугад, подходит новичкам;
   - **средний** играет с умом;
   - **сложный** играет на победу.
5. Когда в лобби 3–6 участников и у всех выбран цвет, нажми **Начать игру**.
   Нужен хотя бы один живой игрок. При 5–6 участниках карта будет большой.

Нажатие на имя в лобби убирает игрока. Живой игрок после этого зайти снова не сможет, бот просто исчезнет.

### Игроки
1. Отсканируй QR с телевизора. Можно и открыть `hexland-540c6.web.app` и ввести PIN.
2. Введи имя и выбери свободный цвет.
3. Дождись, пока ведущий нажмёт «Начать».

### Если ведущий тоже играет
- **Ведущий играет с ноутбука у телевизора.** В лобби есть ссылка «экран игрока в отдельном окне». Телевизор показывает общую карту, а на ноутбуке в отдельном окне видны твои карты.
- **Ведущий играет с телефона, а телевизора нет.** Открой `host.html` прямо на телефоне и в лобби нажми **Играть с этого устройства**.
  Хост и боты работают в той же вкладке. Сверху есть панель ведущего: PIN, «+ бот», «Начать» и меню.
  Во время игры переключайся между «Мой экран» и «Общая карта».
  Так можно сыграть и одному против ботов.

## Во время игры

### На телевизоре
- В центре карта, по краям игроки: очки, количество карт, рыцари, длина дороги, бонусы и статус связи.
- Сверху написано, чей ход, ниже журнал событий.
- В меню ведущего есть **Пропустить ход** (если кто-то завис) и **Закрыть комнату**.
- Кнопка 🔊/🔇 выключает звук сразу во всех вкладках игры на этом устройстве.

### На телефоне
- Кнопки: **🎲 Бросить кубики**, затем **Дорога / Поселение / Город / Карта** (на них подписана цена), **🤝 Обмен** и **Конец хода**.
  После нажатия «Дорога», «Поселение» или «Город» на карте подсвечиваются только те места, куда можно строить.
- **☰** открывает цены построек и кнопку выхода из игры.
- Обмен с игроками:
  - активный игрок предлагает обмен всем;
  - остальные принимают, отказываются или присылают встречное предложение;
  - активный игрок выбирает, с кем меняться.

### Связь пропала или страница обновилась
- Достаточно снова открыть сайт: игрок вернётся на своё место с теми же картами. PIN заново вводить не нужно.
  Это работает даже после закрытия вкладки, но только на том же телефоне и в том же браузере.
- Пока игрока нет, на телевизоре идёт таймер. Если игрок не вернулся к своему ходу:
  - **«за него играет бот»:** место занимает средний бот. Игрок сможет вернуться и забрать место обратно;
  - **«решает ведущий»:** на телевизоре кнопки «Ждать дальше», «🤖 Отдать боту» и «Пропустить ход» (при сбросе на 7 вместо пропуска «Сбросить за него»).
- Ведущий тоже может обновить страницу: игра продолжится с того же места, а игроки пока увидят «Ждём ведущего…».

### Выйти посреди партии
**☰ → 🚪 Выйти из игры → «Точно выйти?» → выбери, какой бот доиграет за тебя.**
Карты, постройки и очки остаются, дальше за тебя играет бот.
Кнопка **Вернуться в игру** на телефоне забирает место обратно.
Если уйдут все люди, боты доиграют партию сами.

## Коротко о правилах

| Что построить | Цена |
|---|---|
| Дорога | дерево + кирпич |
| Поселение (1 очко) | дерево + кирпич + овцы + пшеница |
| Город (2 очка, ставится на своё поселение) | 3 руды + 2 пшеницы |
| Карта развития | руда + овцы + пшеница |

- **Начало:** каждый ставит поселение и дорогу, потом в обратном порядке ещё по одной паре. За второе поселение сразу даются ресурсы с соседних гексов.
- **Ход:** бросок кубиков, все получают ресурсы с гексов с выпавшим числом (поселение 1 карта, город 2). Дальше активный игрок торгует и строит в любом порядке.
- **Банк:** обмен 4:1. Со своей гаванью 3:1 или 2:1.
- **Выпало 7:**
  - у кого больше 7 карт, сбрасывает половину;
  - разбойник переезжает на другой гекс, и этот гекс перестаёт приносить ресурсы;
  - активный игрок крадёт карту у соседа этого гекса.
- **Карты развития:**
  - **рыцарь** двигает разбойника;
  - **победное очко** засчитывается само;
  - **дороги** — две бесплатные;
  - **изобилие** — 2 любых ресурса;
  - **монополия** — все отдают тебе один ресурс.

  За ход можно сыграть одну карту, но не ту, что куплена в этот же ход.
- **Бонусы по +2 очка:**
  - **самая длинная дорога** — от 5 участков;
  - **самая большая армия** — от 3 рыцарей.
- **Победа:** первый, кто наберёт нужное число очков (обычно 10) в свой ход.

## Для разработчика

### Что где лежит
| Путь | Что это |
|---|---|
| `src/engine/` | правила игры: чистый движок без сети (`applyAction`) |
| `src/bots/` | боты трёх уровней |
| `src/net/` | Firebase: комнаты, вход, переподключение. Настройки проекта в `src/net/config.ts` |
| `src/host/` | экран ведущего (`host.html`) |
| `src/play/` | экран игрока (`index.html`) |
| `test/` | тесты движка и ботов, `test/live/` — живые тесты с настоящей базой |
| `database.rules.json` | правила безопасности базы |
| `PLAN.md` | подробный план, решения и статус проекта |

### Запустить у себя
Нужен Node.js 22 или новее. В папке проекта выполни:

```powershell
npm install
```

```powershell
npm run dev
```

- Vite покажет два адреса: `Local` и `Network`. Хост открывается как `<адрес>/host.html`.
- Для игры с телефонов открой хост по адресу **Network**: с адреса `localhost` QR на телефоне не откроется. Телефоны должны быть в той же Wi-Fi сети.
- Несколько игроков в одном браузере: открой вкладки с `?test=1`, например `http://localhost:5173/?test=1`. Тогда у каждой вкладки свой игрок.

### Проверки
Тесты движка и ботов:
```powershell
npm test
```

Проверка типов:
```powershell
npm run typecheck
```

Живые тесты с настоящей базой (нужен интернет):
```powershell
npm run test:live
```

### Выложить на сайт
Один раз войди в Firebase:
```powershell
firebase login
```

Собрать проект и выложить сайт вместе с правилами базы:
```powershell
npm run deploy
```

Выложить только правила базы:
```powershell
npm run deploy:rules
```

### Свой проект Firebase (если понадобится)
1. https://console.firebase.google.com → **Создать проект**.
2. **Build → Realtime Database → Create Database**: регион **Belgium (europe-west1)**, режим **locked**.
3. **Build → Authentication → Sign-in method → Anonymous → Enable**.
4. ⚙ **Project settings → Your apps → `</>`**. Скопируй `firebaseConfig` в `src/net/config.ts`.
5. В папке проекта выполни `firebase use --add`, выбери новый проект и задай псевдоним `default`, затем `npm run deploy`.

> `apiKey` в `config.ts` не секретный: его видит каждый, кто открывает сайт. Защиту дают правила из `database.rules.json`.
> Бесплатного тарифа Firebase (Spark) хватает примерно на 100 одновременных подключений. Это десятки параллельных партий.
